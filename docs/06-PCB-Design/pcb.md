## Overview

This PCB is designed to support a solenoid valve, PIC Nano MicroChip microcontroller, and a speaker circuit. The PCB design is imperative for the project in EGR 304; this is just one of 4 PCB boards. My group mates of Team 211 will have the other boards. The boards will work in a hub-and-spoke system. See [team block diagram](https://egr304-2025-f-211.github.io/06-Team-block-diagram/) for more information about the teams' boards and where this board fits.
